## Architecture

A fundamental divergence from traditional visual novels. Instead of branching paths hard-coded into `.rpy` scripts, this engine acts as a **reactive frontend** runtime visualization terminal for a generative backend.

## Core Mechanics

- The backend — driven by local LLMs and diffusion-based image generators — creates narrative, character states, and visual assets dynamically during the simulation loop.
- Replaces traditional Ren'Py script statements (`show`, `say`, `menu`) with programmatic Python equivalents to give the backend absolute control.
- **Runtime Asset Bridge.** Circumvents Ren'Py's initialization scan to load dynamically generated files (via ComfyUI) from absolute paths without crashing.
- **Dynamic State.** As the user interacts, the system summarizes history into a smart memory buffer to stay within the LLM context window.

## Overview

Clay Film turns a written plan into a narrated short film without leaving the machine. Every image, video, speech and caption model runs locally through ComfyUI, audio.cpp and Python, on two RTX 5060 Ti 16GB cards. The planner can call any OpenAI-compatible endpoint, local or hosted. *Anubis*, a 4.8-minute film of 38 shots, was the first piece made with it.

## Pipeline

1. **Plan.** A JSON file lists the shots: location, camera, where each person stands, and the line of narration each shot carries. It can be written by hand, by a local LLM, or by an agent through an MCP server.
2. **Clay Blockout.** Each shot is built as metric 3D geometry in untextured clay. Camera height, lens and scale are set in metres, so composition and perspective are fixed before any diffusion model runs.
3. **Stills.** Qwen-Image 2.1 edits each clay frame into a finished image. Shots with no blockout use its text-to-image mode.
4. **Motion.** MiniMax H3 animates each still into a clip, and a cut detector flags clips where the model invented a cut.
5. **Assembly.** Clips are graded, laid under the narration and encoded to MP4.

## Key Features

- **Voice Booth.** A local web app plays the finished picture with the script highlighted in time, records takes in the browser, denoises and levels them, and builds the voiced MP4. Captions use the script text, timed by faster-whisper and burned in with libass.
- **Studio and MCP Server.** A FastAPI web UI edits plans and reruns any stage per shot, and the same functions are exposed over MCP so an agent can drive a film end to end.
- **Prompting Rules from Renders.** Failure modes found while rendering *Anubis* are enforced or documented in the code: a shot may name only what its still shows, and actions must be visible at the figure's scale, or the motion model cuts away.

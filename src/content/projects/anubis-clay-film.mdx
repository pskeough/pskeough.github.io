## Overview

This repository holds the pipeline used to make *Anubis*, a narrated short film adapted from a 634-word prose piece. The image, video, speech and caption models run locally on two RTX 5060 Ti 16GB cards with 32GB of system RAM.

## Pipeline

1. **Plan.** A JSON plan lists the shots: location, camera, where each person stands, and the line of narration each shot carries. The plan can be written by hand, by a local LLM, or by an agent through an MCP server.
2. **Clay blockout.** Each shot is built as metric 3D geometry in untextured clay. Camera height, lens and scale are set in metres, so composition and perspective are fixed before any diffusion model runs.
3. **Stills.** Qwen-Image 2.1 edits each clay frame into a finished image. Shots with no blockout use its text-to-image mode.
4. **Motion.** MiniMax H3 animates each still into a clip. A cut detector flags clips where the model invented a cut.
5. **Assembly.** Clips are graded, laid under the narration and encoded to MP4.

## Voice booth

The repository also includes a local web app for recording narration against the finished picture. It plays the cut with the script highlighted in time, records takes in the browser, denoises and levels them, and builds the voiced MP4. Captions use the script text, timed by faster-whisper, and are burned in with libass.

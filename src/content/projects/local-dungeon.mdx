## Architecture

This application is an immersive, local-first AI roleplay engine. Unlike traditional visual novels with hard-coded branching paths, this system generates the entire world, characters, narrative, and accompanying imagery on the fly, entirely locally.

## Core Mechanics

- **Dynamic Visuals & State:** The backend utilizes Qwen 2.5 14B to drive the narrative and ComfyUI (Stable Diffusion) to visualize it. The scene updates visually every few turns.
- **Visual Mode:** Users can pause the text-based roleplay and ask the AI to generate a specific image based on a description of the current scene.
- **Smart Memory:** As the user interacts, the system automatically summarizes the interaction history into a smart memory buffer. This ensures the AI stays within the context window without losing track of past events or characters.
- **Gallery & Persistence:** Maintains a gallery of all generated visuals and preserves the world state across sessions.

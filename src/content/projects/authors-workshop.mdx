## Architecture

**AuthorsWorkshop** is a comprehensive, local-first web application designed as a universal editing environment. Built around a Flask + SQLite backend and a Vite-bundled vanilla JS frontend, the application exposes Google's Gemini AI models through a polished, stateless, book-themed UI.

## Core Mechanics

- **Style Analysis Engine:** A highly sophisticated 3-pass parallel pipeline that extracts lexical, structural, and tonal metrics from text to reverse-engineer an author's prose style into a reusable JSON profile.
- **Character Deep Dive Workshop:** A multi-threaded NLP suite that identifies characters and performs deep psychological, relationship, and flaw analyses, ultimately allowing the user to role-play chat with the character.
- **RAG Chat & Contextual Editor:** Users can chat with their document and execute edits where the AI is intrinsically informed by attached world-building snippets and the active style profile.
- **Book Splitter & Multimedia Generation:** Automatically splits raw manuscripts into chapters via regex, and features dynamic playlist generation, Mermaid.js flowcharts, and Imagen3 character portrait rendering.

## Editing Discipline

Every AI operation—generation, editing, chat, analysis—is deeply context-sensitive and isolated per user. The system ensures the author remains in complete control, leveraging AI not as a replacement for creativity, but as an analytical sounding board and structural editor.
